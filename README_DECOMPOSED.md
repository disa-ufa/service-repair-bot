# Проект бота — декомпозиция больших модулей

В проекте были «разрезаны» два крупных файла, чтобы дальше было удобно править логику по частям и не держать в одном файле тысячи строк.

## Что изменилось

### 1) `bot/handlers/orders.py`
Раньше это был монолитный файл со всеми обработчиками заявок.
Теперь это **фасад**, который только собирает роутеры из отдельных модулей:

- `bot/handlers/orders_admin.py` — всё для админов/диспетчера:
  - создание заявки
  - редактирование заявки
  - списки заявок
  - просмотр карточки/файлов
  - назначение/снятие мастера
  - подтверждение оплаты (PAID)

- `bot/handlers/orders_master.py` — всё для мастера:
  - принять заявку
  - смена статуса
  - модернизация (ДР) + комментарий
  - закрытие заявки (суммы, чеки, договор, гарантия, акт)
  - отправка скрина сдачи

- `bot/handlers/orders_stats.py` — кнопка статистики в меню.

Импорт в `dispatcher.py` не менялся: `from bot.handlers.orders import router as orders_router` — работает как раньше.

### 2) `bot/db/repo.py`
`repo.py` стал **фасадом** и переэкспортирует функции из подмодулей:

- `bot/db/repo_users.py`
- `bot/db/repo_offers.py`
- `bot/db/repo_orders.py`
- `bot/db/repo_files.py`
- `bot/db/repo_stats.py`
- `bot/db/repo_reports.py`

Во всём проекте по‑прежнему можно использовать `from bot.db import repo`.

## Почему так удобнее
- проще находить нужную логику (по роли/по подсистеме)
- меньше конфликтов при правках
- проще тестировать/дополнять отдельные части (например, закрытие заявки или отчёты)
